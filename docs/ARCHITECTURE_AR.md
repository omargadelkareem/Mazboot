# بنية تطبيق العميل والصنايعي

## مصدر البيانات

مسار العميل يتعامل مع `CustomerRepository` ومسار الصنايعي يتعامل مع `ProviderRepository`. عند نجاح Firebase يستخدم التطبيق نسختي Firebase، وعند غياب الإعدادات أو استخدام `DEMO_MODE=true` يستخدم النسخ المحلية.

هذا يجعل نفس الشاشات ومسارات الاستخدام قابلة للاختبار قبل تجهيز المشروع السحابي.

## المسارات الأساسية في Realtime Database

| المسار | الاستخدام |
|---|---|
| `/categories` | الأقسام النشطة وترتيبها |
| `/public_providers` | الملف العام للفني وحالة التوثيق والاشتراك |
| `/provider_applications/{uid}` | طلب انضمام الصنايعي وحالة المراجعة والتفعيل |
| `/users/{uid}` | بيانات العميل وعناوينه وFCM token |
| `/favorites/{uid}` | الفنيون المحفوظون |
| `/orders/{orderId}` | الطلب وحالته |
| `/order_actions/{orderId}` | طلبات الإلغاء التي تحتاج معالجة موثوقة |
| `/chats/{orderId}` | بيانات المحادثة ورسائل الطلب |
| `/reviews/{providerId}` | التقييمات المرتبطة بطلب مكتمل |
| `/notifications/{uid}` | صندوق إشعارات العميل داخل التطبيق |

## صلاحيات تغيير حالة الطلب

- العميل ينشئ الطلب بحالة `sent` ولا يغير الحالة مباشرة.
- الفني المرتبط بالطلب أو الإدارة فقط ينتقلان بين الحالات المسموحة.
- العميل يطلب الإلغاء في `order_actions`، ثم Cloud Function أو الإدارة تعتمد الطلب وتحدث الحالة.
- التقييم لا يقبل إلا من صاحب طلب حالته `completed`.

## الصور

الصور تتحول إلى Base64 بعد الضغط وتخزن داخل الطلب أو الرسالة. `ImageService` يطبق حد الحجم محليًا، وقواعد RTDB تطبق حدًا ثانيًا على الخادم.

## إدارة الحالة

- `AuthCubit`: جلسة Google المستقلة للعميل.
- `ProviderAuthCubit`: دخول الصنايعي المستقل بالموبايل وكلمة المرور والتحقق من القبول والاشتراك.
- `ProviderApplicationCubit`: إرسال طلب الصنايعي ومتابعة قرار الإدارة لحظيًا.
- `ProviderWorkspaceCubit`: الملف المهني والتوفر وطلبات الصنايعي ومحادثاته.
- `ProviderChatCubit`: رسائل الصنايعي داخل كل طلب.
- `HomeCubit`: الأقسام والفنيون العامون.
- `OrdersCubit`: الطلبات والإنشاء والإلغاء والتقييم.
- `ProfileCubit`: بيانات العميل والعناوين.
- `FavoritesCubit`: المفضلة.
- `ConversationsCubit` و`ChatCubit`: المحادثات والرسائل.
- `NotificationsCubit`: إشعارات الحساب وحالة القراءة.
