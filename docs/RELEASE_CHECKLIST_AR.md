# قائمة ما قبل النشر

- [ ] استبدال بيانات وصور Seed بفنيين حقيقيين وموافقات استخدام الصور.
- [ ] جعل `public_providers` IDs مساوية لـFirebase Auth UIDs للفنيين.
- [ ] اختبار Google Sign-In على Android حقيقي وإضافة SHA-1 وSHA-256 لكل مفتاح توقيع.
- [ ] تفعيل Email/Password واختبار دخول الصنايعي بالموبايل وكلمة المرور بعد إعادة فتح التطبيق.
- [ ] التأكد أن الانتقال بين العميل والصنايعي يسجل خروج الهوية الحالية ولا يربط الحسابين.
- [ ] نشر واختبار قواعد RTDB باستخدام Firebase Emulator Suite.
- [ ] إنشاء Cloud Functions لتحديث الإشعارات، معالجة طلب الإلغاء، ومزامنة اشتراك الفني.
- [ ] إضافة مفتاح توقيع Release وإزالة `signingConfigs.debug` من Release.
- [ ] إضافة رقم وبريد الدعم عبر Dart defines أو نظام إعدادات آمن.
- [ ] مراجعة شروط الاستخدام وسياسة الخصوصية بواسطة مستشار قانوني وإضافة بيانات الكيان التجاري.
- [ ] وضع سياسة واضحة للتسعير والإلغاء والشكاوى والاسترداد مع توضيح عدم وجود رسوم معاينة مسبقة.
- [ ] إعداد Android notification icon أبيض مخصص بدل استخدام launcher icon إن لزم.
- [ ] اختبار حالات فقد الإنترنت، إلغاء نافذة Google، رفض صلاحية الموقع والكاميرا، وقاعدة فارغة.
- [ ] تشغيل `flutter analyze` و`flutter test` ونسخة `flutter build appbundle --release` على Flutter 3.24.3.
- [ ] مراقبة Crashlytics/analytics بعد موافقة المستخدم لو تمت إضافتهما.
- [ ] تقييم نقل الصور من Base64 إلى Object Storage عند زيادة الحجم أو الاستخدام.
